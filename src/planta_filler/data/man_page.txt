NAME
    planta-filler {version} - automatic timesheet filling for PLANTA Pulse

SYNOPSIS
    planta-filler --url URL [OPTIONS]
    python3 -m planta_filler --url URL [OPTIONS]

DESCRIPTION
    Opens the PLANTA timesheet in Firefox, reads the attendance hours
    ("Anwesend") of every selected day and distributes them over the task
    rows according to a strategy. Cells are typed into the page exactly as
    you would do by hand, so PLANTA saves them the usual way.

OPTIONS
  What to fill
    --url URL
        PLANTA URL. Default: {default_url}

    --week SPEC[,SPEC...]
        Week(s) to process, in the given order. Each SPEC is a relative
        offset (0 = current week, -1 = last week, 1 = next week) or an ISO
        week such as 2024-W05. Pass several weeks as ONE argument, e.g.
        --week=-2,-1,0 (the "=" avoids the shell or argparse treating "-2"
        as an option). Default: {default_week}

    --weekdays DAYS
        Comma-separated weekdays: 0=Mon 1=Tue 2=Wed 3=Thu 4=Fri 5=Sat 6=Sun.
        Default: {default_weekdays}

    --exclude INDICES
        Zero-based task row indices that are never changed, for filling as
        well as for --reset. Example: --exclude 0,2

  How to fill
    --strategy NAME
        equal          the same amount for every row
        random         random amounts that add up to the day total
        copy_reference the proportions of a reference CSV (see FILES)
        Default: {default_strategy}

    --reference-file PATH
        Reference CSV for copy_reference. Whole-week files have one column
        per weekday; a file with a single value column applies to every
        weekday. If the file is missing, malformed or has a different
        number of rows than PLANTA, the affected days fall back to equal
        weights and a warning is printed. Default: the packaged example.

    --post-randomization FACTOR
        Jitter every value by up to FACTOR of itself (0.0 <= FACTOR < 1.0)
        while keeping the exact day total. Default: {default_post_randomization}

    --reset
        Set the selected cells to 0 instead of filling them.

    --export-reference PATH
        Write the values currently shown in PLANTA for the selected week to
        PATH as a whole-week reference CSV, then exit without changing
        anything. A convenient way to turn a manually filled week into a
        template for copy_reference.

  Browser
    --persistent / --no-persistent
        Keep cookies and the login in a Firefox profile so you only have
        to log in once. Profile: {profile_dir}
        Default: {default_persistent}

    --headless
        Run Firefox without a window. Requires an already logged-in
        persistent profile because nobody can type the password.
        Default: {default_headless}

    --login-only
        Open PLANTA, wait until you are logged in and exit without changing
        any hours. Use it once to prepare the persistent profile for later
        --headless runs (for example inside a container).

    --delay SECONDS
        Pause between two field updates. Increase it on slow connections.
        Default: {default_delay}

    --close-delay SECONDS
        Keep the browser open this long after the run so you can check the
        result. Default: {default_close_delay}

  Output
    -v, --verbose   show debug output
    -q, --quiet     show only warnings and errors
    --version       print the version and exit
    --man           show this manual page and exit
    -h, --help      show the short help and exit

LOGIN
    On the first run a browser window opens and the program waits for you to
    log in. Press ENTER in the terminal once the timesheet is visible. With
    --persistent (the default) the session is stored and later runs, also
    headless ones, start directly.

FILES
    {profile_dir}
        Firefox profile used with --persistent.

    Reference CSV (copy_reference), whole-week format:
        ,Mo,Di,Mi,Do,Fr
        1,6.00,4.00,3.00,2.00,0.00
        2,1.00,1.00,2.00,2.00,0.00
    The first column is a row index and is ignored. Labels may be German or
    English, abbreviated or full. Values are weights: only their ratio per
    day matters, the day total always comes from PLANTA.

EXIT STATUS
    0   success
    1   the run failed (browser, login, PLANTA page)
    2   invalid arguments

TROUBLESHOOTING
    "Could not start Firefox"
        Install Firefox and geckodriver and put geckodriver on your PATH.
    "The page title ... does not look like PLANTA Pulse"
        Check the URL; connect to the VPN if PLANTA is only reachable there.
    "The timesheet did not appear"
        You are not logged in. Run once without --headless and log in.
    Values are not saved
        Increase --delay (e.g. --delay 0.5).
